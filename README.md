# DiskSense

> 便携式 AI 磁盘文件管理器 —— 由 LLM Agent 驱动的本地磁盘语义化管理 Agent Skill 包

融合 **Everything 的检索速度 + SpaceSniffer 的可视化 + 文件管理器的操作能力 + LLM 的语义推理**。

- 需求源头：[方案书.md](方案书.md)
- 开发规范：[CONTRIBUTING.md](CONTRIBUTING.md)

## 状态

按方案书分阶段实现中（每阶段一次提交，详见 git log）。完整使用说明将在交付阶段补全。

## 三大铁律

| 铁律 | 说明 |
| :--- | :--- |
| 绝对隐私 | 零内容读取，仅允许读取文件头 16 字节魔数用于格式判定 |
| 纯便携无痕 | 零注册表、零服务、零自启；所有状态位于 `Data/`，删除目录即卸载 |
| 全操作可回溯 | 删除强制走回收站；所有操作落 SQLite 日志，支持一键回滚 |
